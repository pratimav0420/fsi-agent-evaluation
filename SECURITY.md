# Security Policy

## Reporting

Do not open a public issue for a suspected vulnerability or exposed credential. Contact the
repository owner privately through GitHub and include the minimum information needed to reproduce
the concern.

## Data boundary

This repository accepts synthetic data only. Never submit real customer, policy, claim, identity,
endpoint, tenant, subscription, or credential data. Revoke any credential immediately if it is
accidentally disclosed.

## Supported version

Security fixes are applied to the latest commit on `main`. The project is a reference implementation,
not a production claims system or compliance certification tool.
