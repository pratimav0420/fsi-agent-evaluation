# Changelog

All notable changes to this project are documented here.

## 0.2.0 - 2026-08-26

- Added ten requirement-traceable controls and 20 curated synthetic cases.
- Added deterministic local passing and retrieval-before-entitlement profiles.
- Added severity-aware gates, baseline comparison, and JSON/Markdown/JUnit evidence.
- Added sanitized live Foundry recordings and credential-free replay.
- Validated structured GPT-4.1 function calls and experimental Tool Call Accuracy evaluation.
- Added a fail-closed check for deployments that return tool-like text instead of structured calls.
- Added GitHub Actions offline and OIDC-based live validation paths.
